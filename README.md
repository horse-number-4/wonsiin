# 원시인 — 사격제원 계산기

오프라인 동작 PWA. 박격포 사격제원과 저격 탄도를 계산합니다.

## 박격포

표적 위치 결정 4가지 → 사표 보간 → 편각·고각

| 방법 | 입력 |
|---|---|
| 방안좌표법 | 포대·표적 좌표 |
| 극표정법 | 관측소 좌표 + 관측방위각·거리·수직전이량 |
| 기록점전이법 | 기록점 좌표 + 편향·거리증감·상하 |
| 관측자 수정 | 탄착점 + OT선 기준 좌우·원근·상하 |

좌표 기하(거리·방위각·복각)와 편각 변환은 전부 계산합니다.
**사거리별 고각은 사표 실측값이라 계산할 수 없습니다** — 부대 사표를
직접 입력하면 보간합니다. 「예시 넣기」 값은 동작 확인용 가짜 숫자입니다.

## 저격

G1/G7 표준 항력함수, 습공기 밀도(Magnus), 시선 정렬 좌표계 수치적분,
Miller 안정계수, Litz 스핀드리프트, 코리올리.

## 쓰기 전에

- 총구속도·BC는 크로노그래프 실측과 실사격 탄착으로 교정해야 맞습니다
- 기압은 해면환산이 아니라 **현재 위치 실측 기압**을 넣으세요
- 편각 부호 규약은 부대 SOP마다 다릅니다 — **아는 제원으로 역검산 후 사용**
- MIL(mrad, 6283)과 밀(6400)은 다른 단위입니다

모든 계산은 기기 안에서 처리되고 데이터는 어디로도 전송되지 않습니다.
